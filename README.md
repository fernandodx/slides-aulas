# Slides de Aulas — Plataforma Interativa em Vue 3 (Material You + Firebase)

Plataforma de slides acadêmicos interativos construída com **Vue 3**, **Material Design 3 (Material You)**, **MVVM / SOLID** e **Firebase** (Analytics, Remote Config, Firestore, App Hosting e URLs amigáveis com Vue Router).

## 🚀 Como Executar Localmente

### 1. Iniciar o servidor de desenvolvimento
```bash
npm run serve
```
Acesse no navegador: **`http://localhost:8080`**

---

## 🛠️ Outros Comandos Úteis

### Compilar para Produção (Build)
```bash
npm run build
```

### Executar Linter
```bash
npm run lint
```

---

## ⌨️ Navegação nos Slides
- **Setas Direita / Esquerda**: Avança ou volta o slide atual
- **Barra de Espaço / PageDown / PageUp**: Navegação alternativa de slides
- **Tecla F**: Ativa / Desativa modo Tela Cheia (Fullscreen)
- **Tecla M / G**: Abre o menu de visão geral em miniaturas (Overview Grid)
- **Tecla Esc**: Fecha o menu de miniaturas
